# Photo Log List Redesign Brief

## Purpose

- Help the user recognise and open the right photo log without decoding a cramped metadata blob.

## Primary User Task

- Pick a log, continue it, view contents, or open details.

## Visual Hierarchy

- Group scope label first.
- Log title next, readable over one or two lines.
- Current/copied/locked state as compact badges.
- Counts as small metric badges.
- Source path as secondary text.
- Actions in a wrapping grid below the metadata.

## macOS Direction

- Use native small controls, SF Symbols where useful, compact spacing, subtle separators, and no decorative colour.
- Do not create card-heavy marketing UI.
- Do not keep all controls in one horizontal row.

## Cognitive Walkthrough

- User identifies the log by title.
- User recognises state from badges.
- User selects the right action from a visible action grid.
- User sees lock message if an action is disabled.
